整支 main() 逐段拆解

scripts/run_fitbit_report_neurokit.py — main()

def main() -> None:
    parser = argparse.ArgumentParser(description="...")
    parser.add_argument("--image", required=True, type=Path)
    parser.add_argument("--output-dir", default=PROJECT_DIR / "outputs", type=Path)
    parser.add_argument("--sampling-rate", default=250, type=int)
    args = parser.parse_args()

第一段：讀取命令列參數。 這是函式呼叫（Lesson 2）——ArgumentParser() 是別人寫好的工具（從 import，Lesson 5 教的 argparse），負責讀懂你在 Terminal 打的 --image xxx.pdf 這種參數。跑完這幾行，args.image、args.output_dir、args.sampling_rate 就是你在 Terminal 打的那些值——本質上就是一堆變數（Lesson 1）。

    image = np.array(Image.open(image_path).convert("RGB"))
    raw = extract_blue_trace(image, DEFAULT_STRIPS, args.sampling_rate)
    clean = nk.ecg_clean(raw, sampling_rate=args.sampling_rate)
    processed, info = nk.ecg_process(clean, sampling_rate=args.sampling_rate)

第二段：把圖片變成訊號、清乾淨、分析。 這四行是一條「資料流」：圖片 → extract_blue_trace()（Lesson 4 的 for 迴圈，把圖片切段抽出訊號）→ nk.ecg_clean()（NeuroKit2 這個套件，Lesson 5 的 import neurokit2 as nk，負責濾掉雜訊）→ nk.ecg_process()（NeuroKit2 負責找出心跳、R-peak 等醫學特徵）。每一行都是變數 = 函式呼叫，前一行的結果變成下一行的材料。

    stem = output_stem(image_path, args.source_name)
    csv_path = output_dir / f"{stem}_fitbit_neurokit.csv"
    plot_path = output_dir / f"{stem}_fitbit_neurokit.png"

第三段：準備輸出檔名。 這就是 Lesson 1、Lesson 2、Lesson 3 一路拆解的 output_stem()——現在你知道它整支函式在幹嘛、if/else 那行在防什麼情況，也知道它是被這裡呼叫的。

    out = pd.DataFrame({
        "ECG_Raw": raw,
        "ECG_Clean": processed["ECG_Clean"],
        "ECG_Rate": processed["ECG_Rate"],
        "ECG_R_Peaks": processed["ECG_R_Peaks"],
    })
    out.to_csv(csv_path, index=False)

第四段：把結果存成表格。 {...} 是 dict（Lesson 6）——每個 key（像 "ECG_Raw"）對應一欄資料。pd.DataFrame(...) 把這個 dict 變成一張表格（pd 就是 Lesson 5 教的 import pandas as pd），存成 CSV 檔。

    summary = {
        "image": str(image_path),
        "samples": int(len(raw)),
        "mean_hr_bpm": float(np.nanmean(rate)),
        ...
    }
    summary_path.write_text(json.dumps(summary, indent=2), encoding="utf-8")

第五段：把摘要存成 JSON。 又是一個 dict（Lesson 6），這次用 json.dumps(...)（import json）把它轉成 JSON 格式的文字，寫進檔案。

if __name__ == "__main__":
    main()

最後一段：真正啟動整支程式。 這是 Lesson 3 教的那句固定寫法——只有直接執行這支檔案時，才會呼叫 main() 把上面全部串起來跑一遍。
