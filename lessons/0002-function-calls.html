函式（Function）：把一段邏輯包成一個可以重複呼叫的工具

上一課看懂了「變數」這個箱子。這一課看懂「函式」——一個把好幾行邏輯包起來、取個名字、之後隨時可以呼叫的箱子。

跟你的目標有什麼關係 這個 repo 裡幾乎每支 script 都是「一堆函式 + 一個 main() 把它們串起來」。看懂函式怎麼定義、怎麼呼叫，你才看得懂程式碼是「誰在什麼時候用了誰」，而不是一堆散落的敘述。

1. 先看一個「真的」屬於你專案的函式

來自 scripts/run_fitbit_report_neurokit.py——上一課那行 timestamp = ... 其實是這個函式裡的一部分：

scripts/run_fitbit_report_neurokit.py

def output_stem(input_path: Path, source_name: str | None = None) -> str:
    source = Path(source_name).stem if source_name else input_path.stem
    timestamp = datetime.now().strftime("%d%m%Y_%H%M%S")
    return f"{source}_RR_{timestamp}"

這個檔案後面的 main() 裡，有另一行程式碼會「呼叫」這個函式：

stem = output_stem(image_path, args.source_name)

第 2 行那個 if source_name else 是條件判斷（if/else），下一課會教，這一課先跳過、不用管它在幹嘛。

2. 逐字拆解

片段這是什麼白話解釋
def 定義函式的關鍵字
(define)		 告訴 Python：「接下來我要教你一個新招式，先把它記起來，還沒要執行。」
output_stem 函式名稱 你自己取的名字，之後要用這個招式就喊它的名字。取名習慣跟變數一樣：看名字要猜得出用途。
(input_path, source_name=None) 參數
(parameters)		 這個函式需要的「材料」。input_path 一定要給；source_name 可以不給，不給的話預設是 None（代表「沒有」）。
-> str 回傳型別提示
(return type hint)		 「這個函式做完會交回一段文字（str）。」這只是提示、方便閱讀，Python 不會強制檢查。
return f"{source}_RR_{timestamp}" 回傳值
(return)		 函式做完事，把結果「交回去」給呼叫它的地方。函式跑到 return 就結束了。
output_stem(image_path, args.source_name) 呼叫函式
(function call)		 真正執行這個招式：把 image_path 放進 input_path 這個箱子、把 args.source_name 放進 source_name 這個箱子，然後照函式裡的邏輯跑一遍，最後把 return 的結果存進 stem。

3. 用更簡單的例子鞏固

def greet(name):
    return "Hello, " + name

message = greet("Vic")
print(message)

def greet(name):：定義一個叫 greet 的函式，需要一個材料 name。
return "Hello, " + name：把 "Hello, " 跟 name 接在一起，交回去。
greet("Vic")：呼叫它，把 "Vic" 放進 name，得到 "Hello, Vic"，存進 message。

動手做： cd ~/Documents/ecgtizer-neurokit2 && source ecg_env/bin/activate && python3，貼上上面那個 greet 函式（含 def 那一行到 return），按 Enter，再貼 print(greet("Vic"))。接著試著自己改一個函式：讓它接收兩個材料（例如 name 跟 age），回傳一句組合起來的話。
