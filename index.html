讀懂 ecgtizer 的 Python 課

跟著一個真實的 ECG 訊號分析專案（ecgtizer-neurokit2，私有 repo）的原始程式碼，從完全新手開始學 Python。每一課都直接拆解專案裡真的存在的一行程式碼，不是抽象的教科書範例。

目標 給任何一個這個專案裡 15 行以內的函式，看得懂逐行在做什麼，不用查字典、不用等別人翻譯程式碼。

課程進度

  • Lesson 1 — 變數（Variable）：從 output_stem() 這個函式裡的一行程式碼開始，搞懂 = 賦值跟 print()。
  • Lesson 2 — 函式（Function）：看懂 output_stem() 整支函式怎麼定義、怎麼被呼叫，def / 參數 / return 在幹嘛。
  • Lesson 3 — 條件判斷（if / else）：補回三元運算式，並看懂幾乎每支 script 都有的 if __name__ == "__main__":。
  • Lesson 4 — for 迴圈：看懂 extract_blue_trace() 怎麼用迴圈把 ECG 訊號一段段切出來。
  • Lesson 5 — import：看懂檔案開頭那一大串 import，跟 numpy as np 這種暱稱寫法。
  • Lesson 6 — 清單與字典（list / dict）：DEFAULT_STRIPS 跟 summary 這兩種容器怎麼用。
  • Lesson 7 — 整合：讀完一支完整 script：壓軸課，把前六課串起來，逐段讀完 main()。

目前規劃的 7 課都上完了。之後有新的一課，會加進這個清單。
