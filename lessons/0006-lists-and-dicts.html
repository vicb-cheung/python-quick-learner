清單與字典（list / dict）：兩種裝很多東西的箱子

變數是裝「一個」東西的箱子。這一課看兩種裝「很多」東西的箱子——list 跟 dict——這個專案幾乎每支檔案都同時用到兩種。

跟你的目標有什麼關係 Lesson 4 的 strips、還有到處看到的 [...] 都是 list；程式碼裡任何用「名字」取值（像 summary["samples"]）的都是 dict。分清楚這兩種，你才知道該用數字位置還是用名字去拿資料。

1. 先看「真的」屬於你專案的兩種箱子

scripts/run_fitbit_report_neurokit.py

List——方括號 [ ]，東西按順序排好，用「第幾個」取值：

DEFAULT_STRIPS = [
    (18, 141, 598, 229, 8),
    (18, 258, 598, 344, 8),
    (18, 371, 598, 458, 8),
    (18, 486, 453, 571, 6),
]

Dict——大括號 { }，每筆資料有自己的「名字」（key），用名字取值：

summary = {
    "image": str(image_path),
    "samples": int(len(raw)),
    "mean_hr_bpm": float(np.nanmean(rate)),
}

2. 逐字拆解

片段這是什麼白話解釋
DEFAULT_STRIPS[0] 用位置取 list 的值 拿到第一筆，也就是 (18, 141, 598, 229, 8)。Python 從 0 開始數，所以「第一個」是 [0] 不是 [1]。
for x1, y1, ... in strips: Lesson 4 教過的 for 迴圈 其實就是「依序把 DEFAULT_STRIPS[0]、[1]、[2]、[3] 拿出來」的簡寫，不用自己手動一個個取。
summary["samples"] 用名字（key）取 dict 的值 拿到 key 叫 "samples" 那一筆資料。順序不重要，重要的是名字要對。
"mean_hr_bpm": float(...) dict 的一筆 key-value 冒號左邊是 key（名字，通常是字串），右邊是 value（值，可以是任何東西：數字、文字、甚至另一個 list 或 dict）。

3. 用更簡單的例子鞏固

colors = ["red", "green", "blue"]
print(colors[0])
print(colors[2])

person = {"name": "Vic", "age": 30}
print(person["name"])
print(person["age"])

colors[0] 印出 red（第一個）；person["name"] 印出 Vic（key 是 "name" 的那筆）。

動手做： cd ~/Documents/ecgtizer-neurokit2 && source ecg_env/bin/activate && python3，貼上 colors 跟 person 那兩段。接著自己在 person 裡加一筆 "city": "Hong Kong"（提示：person["city"] = "Hong Kong"），再 print(person) 看看整個 dict 長什麼樣子。
