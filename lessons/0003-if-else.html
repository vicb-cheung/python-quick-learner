條件判斷（if / else）：讓程式碼看情況做不同的事

Lesson 1 跳過的那個三元運算式，這一課補回來講清楚。順便看懂幾乎每支 script 最後都有的 if __name__ == "__main__": 是在幹嘛。

跟你的目標有什麼關係 程式碼不是永遠從第一行照順序跑到最後一行——很多時候它會「看情況」走不同的路。看懂 if/else，你才看得懂一支函式在什麼條件下會回傳不同結果，或是這支檔案在什麼情況下才會真的執行。

1. 先看兩個「真的」屬於你專案的 if

第一個，來自 Lesson 2 那個 output_stem() 函式，上次刻意跳過的那一行：

scripts/run_fitbit_report_neurokit.py

source = Path(source_name).stem if source_name else input_path.stem

第二個，在檔案的最後面：

if __name__ == "__main__":
    main()

2. 逐字拆解：三元運算式

第一種 if 長得跟你以前看過的「if 區塊」不太一樣，它是寫在一行裡的「三元運算式」（ternary expression）：

片段這是什麼白話解釋
A if 條件 else B 三元運算式的公式 唸法是「如果條件成立，取 A；不然，取 B」。整句話算出來是一個值，可以直接存進變數。
Path(source_name).stem 條件成立時的值（A） 如果 source_name 有值，就用它。
source_name 條件本身 Python 會把它當「有沒有值」來判斷：None 或空字串算「沒有」（false），其他字串算「有」（true）——這叫 truthy / falsy，不用跟 True/False 完全相等才算數。
input_path.stem 條件不成立時的值（B） 如果 source_name 是 None（沒給），就退回用 input_path.stem。

3. 逐字拆解：if __name__ == "__main__":

這是幾乎每支 Python script 最後都會出現的固定寫法。__name__ 是 Python 自動幫每個檔案設定的一個變數：

情境__name__ 的值
直接執行這支檔案（例如 python3 run_fitbit_report_neurokit.py）"__main__"
這支檔案被「別的檔案」import 進去用這支檔案自己的檔名

所以 if __name__ == "__main__": main() 的白話翻譯是：「只有在這支檔案被直接執行的時候，才呼叫 main()；如果只是被別的程式借用（import），就不要自動跑。」

4. 用更簡單的例子鞏固

age = 15

if age >= 18:
    print("adult")
else:
    print("minor")

label = "adult" if age >= 18 else "minor"
print(label)

上面兩段做的是同一件事：傳統 if/else 區塊用來「執行不同的敘述」；三元運算式用來「算出不同的值」。

動手做： cd ~/Documents/ecgtizer-neurokit2 && source ecg_env/bin/activate && python3，貼上上面 age = 15 那一段，觀察兩種寫法印出來的結果一不一樣。接著把 age 改成 20 重跑一次。
