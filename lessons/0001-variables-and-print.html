變數（Variable）：從你自己專案的一行程式碼開始

今天的目標很小：看懂 scripts/run_fitbit_report_neurokit.py 裡的一行程式碼，並自己動手寫出同樣邏輯的一行。

跟你的目標有什麼關係 這個 repo 裡幾乎每一行程式碼都在做同一件事：把某個東西「存起來」，之後再拿出來用。這個「存起來的箱子」就叫做變數（variable）。看懂變數，是看懂整個 repo 的第一步——你之後想讀懂 candidate_engine.py 或 apex_hybrid.py 裡的 scoring 邏輯，靠的也是同一個技能，只是箱子變多、變複雜。

1. 先看一行「真的」屬於你專案的程式碼

這一行來自 scripts/run_fitbit_report_neurokit.py 裡的 output_stem() 函式，作用是幫每次分析結果的檔名加上時間戳記：

scripts/run_fitbit_report_neurokit.py

timestamp = datetime.now().strftime("%d%m%Y_%H%M%S")

先別管右邊那串 datetime.now()... 在做什麼——今天只要看懂這一行的「形狀」。

2. 逐字拆解

片段這是什麼白話解釋
timestamp 變數名稱
(variable name)		 你自己取的一個「箱子」的名字，用來裝東西。名字可以自己取，取得有意義（像 timestamp 一看就知道裝的是時間），是好習慣。
= 賦值
(assignment)		 這不是數學課的「等於」！它的意思是「把右邊算出來的東西，放進左邊這個箱子」。方向是右 → 左。
datetime.now().strftime(...) 一個函式呼叫的結果
(function call)		 今天不用懂它怎麼運作，只要知道：它執行完會算出一段「文字」，長得像 "01092026_143022"。

整句話翻成白話：「把 datetime.now().strftime(...) 算出來的那段文字，放進一個叫 timestamp 的箱子裡，之後要用的時候，寫 timestamp 就能拿回它。」

3. 用更簡單的例子鞏固

同樣的形狀，換成最簡單的版本：

x = 5
print(x)

x = 5：建立一個叫 x 的箱子，裡面放數字 5。
print(x)：print(...) 是 Python 內建的「印出來給我看」的函式——把 x 箱子裡目前裝的東西顯示在畫面上。執行這兩行，畫面上會出現：

5

字串（一段文字）也一樣可以放進箱子：

greeting = "hello"
print(greeting)

文字要用引號（" 或 '）包起來，Python 才知道這是「文字」而不是一個變數名稱。

動手做（建議實際打開電腦操作）：
  1. 打開 Terminal，切換到專案資料夾並啟動這個專案自帶的 Python 環境：
    cd ~/Documents/ecgtizer-neurokit2 && source ecg_env/bin/activate
  2. 輸入 python3 進入 Python 互動模式（會看到 >>> 提示字元）
  3. 逐行貼上上面兩組例子（x = 5 / print(x)，以及 greeting = "hello" / print(greeting)），每貼一行按 Enter，觀察畫面顯示什麼
  4. 試著自己取一個新的變數名稱、放一個不同的數字或文字進去，再用 print() 印出來看看
  5. 結束時輸入 exit() 離開

看到你自己打的東西被印出來，就是這一課真正「懂了」的證據——比只看文章有效得多。
