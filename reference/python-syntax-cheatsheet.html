變數（Variable）

寫法意思來自這個 repo 的例子
名稱 = 值 把右邊算出來的值，存進左邊這個名稱（箱子）。= 不是數學等於，是「賦值」。 timestamp = datetime.now().strftime(...)
run_fitbit_report_neurokit.py
x = 5 建立一個裝「數字」的變數。 —
x = "hello" 建立一個裝「文字（字串）」的變數。文字要用引號包起來。 —

印出來看（print）

寫法意思
print(x) 把變數 x 目前裝的東西顯示在畫面上。除錯、確認「這個箱子裡到底是什麼」最常用的工具。

常見混淆

  • =（賦值）跟數學課的「等於」不是同一件事，方向永遠是「右邊 → 左邊」。
  • 變數名稱是你自己取的，跟變數裡裝的內容無關——但取一個有意義的名字（像 timestamp）能讓程式碼更容易讀懂，這也是為什麼這個 repo 裡的變數名稱大多看字面就猜得出用途。
